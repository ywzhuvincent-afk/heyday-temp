# HEYDAY Client Job Workflow App

This is a runnable first-version workflow app for HEYDAY Accounting. It focuses on the operational flow: request client documents, receive uploads, assign jobs, track employee progress, review and bill, and mark payment received.

## What Is Implemented

- Manager dashboard with status counts, overdue work, employee workload, search, status filters, and employee filters.
- Client detail panel with contact profile, file library, assignment form, billing controls, and full status timeline.
- Employee dashboard with assigned jobs and actions for accepting, starting, and completing work.
- Client upload portal with one-time upload tokens generated by the manager's document request action.
- Core workflow state machine with organization isolation fields, role checks, file sections, notifications, billing records, and auditable status events.
- Automated tests for the main workflow behavior.

## Production Upgrade Path

The current version is a browser-run MVP that stores demo data in `localStorage`. For production, replace the storage layer with:

- PostgreSQL tables for organizations, users, clients, jobs, job status events, files, upload requests, notifications, and billing records.
- Private S3-compatible object storage for uploaded files.
- Resend or SendGrid for real request, notification, report, and billing emails.
- Server-side authentication for managers and employees.
- Signed upload URLs or server-side upload handling for customer files.

The workflow functions in `src/workflow.mjs` are intentionally pure and tested so they can be moved behind real API routes later.
